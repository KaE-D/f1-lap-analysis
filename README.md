# F1 Lap Time Analysis

Analysis of lap time differences between F1 teammates (Pérez vs Verstappen,
Abu Dhabi GP 2021), investigating causes of performance variation using
Python and Pandas.

## What's in here
F1 lap time analysis.ipynb` — main notebook with code, charts, and write-up
Data files from the Kaggle "Formula 1 World Championship (1950-2024)" dataset

## Key finding
Raw lap time averages suggested one driver was faster, but excluding pit
stops and safety car periods reversed this conclusion, showing the
importance of cleaning data before drawing performance conclusions.
